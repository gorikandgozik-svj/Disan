# GitHub source export

The ChatGPT plugin release is v1.1.0. This public source export uses a portable SVG icon in place of the original PNG and excludes generated binary preview outputs. Source modules, skills, manifests and automated tests are included. To regenerate screenshots, install Playwright and Chromium and run the browser QA command from README. To regenerate GLB assets, run the procedural tools described in examples/QUICKSTART.md.
